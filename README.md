# PANELS FREE

Native Windows wallpaper app prototype built with Tauri + React + TypeScript.

## Setup

1. Install Node.js 20+
2. Install Rust stable
3. Install Tauri prerequisites for Windows
4. Run:

```bash
npm install
npm run tauri dev
```

## Build

```bash
npm run tauri build
```

## Important

This repository contains the source project, not a prebuilt EXE. Downloading the files alone will not launch the app; it must be built locally on a Windows machine.
